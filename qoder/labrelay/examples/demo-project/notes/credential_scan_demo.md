# 凭据检测样例（合成占位值，不是真实凭据）

这份文件是 LabRelay 安全链路的教学样例，不是可用的凭据。
其中只出现**明显不可用的占位串**，用来演示导入阶段的凭据检测与受限处理。

## 演示内容

配置里如果混进了下面这种写法，导入器会在扫描阶段命中 `api_secret` 规则：

```ini
api_key = LABRELAY_PLACEHOLDER_NOT_A_REAL_KEY
```

LabRelay 的处理顺序是：先扫描 → 命中即把整份资料标为 restricted → 受限资料只保存不索引 →
检索、引用生成和学习路径都不会读到它的正文。因此这份文件在本项目里查不出任何内容，
这是预期结果，不是导入失败。

## 接手新人要记住的规则

- 真实凭据一律不写进仓库、笔记、实验配置或聊天记录，改用运行时的环境变量注入。
- 如果不小心提交了，先撤销并轮换，再补一条交接记录。
- 交接系统给出的都是建议，不会代跑任何清理或运维命令。
