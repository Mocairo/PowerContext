# Demo Research Project

该目录用于存放一个可公开分发的微型科研项目，以便评委和开发者复现 LabRelay 的主要流程。

禁止放入：

- 真实实验室服务器地址、账号或内网信息；
- API Key、数据库密码、私钥或其他凭据；
- 未公开或不可再分发的论文全文；
- 原始大型数据集和模型权重；
- 姓名、联系方式等个人身份信息。

推荐结构：

```text
examples/demo-project/
├── papers/         两篇公开或合成论文节选
├── code/           可小型运行的代码快照
├── experiments/    配置、指标和实验说明
├── notes/          调试笔记和交接说明
└── ops/            服务器、数据与资源使用说明
```

示例资料必须能够支持以下验证问题：

1. 如何复现 baseline；
2. 实验配置在哪里；
3. 历史指标是多少；
4. 已知数据缓存问题是什么；
5. 下一项未完成工作是什么；
6. 实验室资源应如何申请和释放。
