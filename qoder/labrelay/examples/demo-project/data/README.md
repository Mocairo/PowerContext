# 数据说明

## 版本与位置

| 版本 | 位置 | 状态 | 说明 |
| --- | --- | --- | --- |
| v3 | `/data/aurora/v3` | 冻结，只读 | baseline 与所有历史指标所用的数据 |
| v4 | `/data/aurora/v4` | 快照已就绪 | **从未跑过任何实验**，不能当 baseline 的对照 |
| 旧缓存 | `/data/aurora/cache/` | 可清理 | 缓存键不含 `data_version`，复现前必须清空 |

## 结构

- 多变量工业时序，按窗口切分，共 24000 个窗口。
- 切分比例 train 0.8 / val 0.2，测试集是 train/val 之外的留出段，切分写在
  `configs/baseline.yaml` 的 `data` 段。
- 标签只有正常/异常两类，异常样本稀少，所以主指标用 AUROC，F1 只在阈值 0.5 下报告。

## 读取约定

- 训练与评估都通过 `code/train.py` / `code/evaluate.py` 的 `--config` 读配置，
  不要在脚本里硬编码路径。
- `data.require_clean_cache: true` 是校验开关，命中非空缓存时应当直接失败，
  而不是静默复用旧划分。

## 不外发的内容

真实传感器原始流、采集点位、产线标识都不在这个示例里。仓库只保留合成说明，
接手人不需要、也不应该拿到原始数据文件。
